# Проверка комплекта

Проверено 16 сентября 2026 года. Полные сборки выполнены для ESP32-S3; физическая плата в этой среде недоступна, прошивка и работа датчиков на устройстве здесь не проверялись.

## Прошивка

Окружение: ESP-IDF **v5.4.1**, commit `4c2820d377d1375e787bcef612f0c32c1427d183`, Xtensa GCC **14.2.0**, CMake **3.30.5**, Ninja **1.11.1.1**, Python **3.12.14**.

| Конфигурация | Результат | Размер приложения |
|---|---|---|
| `CONFIG_QAV250_OUTPUT_RAW_JSON=y` — по умолчанию | Полная сборка успешна | `0x3ed40` байт |
| `CONFIG_QAV250_OUTPUT_EKF_JSON=y` | Полная сборка успешна | `0x3ef40` байт |

Обе сборки помещаются в раздел приложения `0x100000` байт; свободно около 75%. Использованы драйверы Bosch из этого репозитория и стек основной задачи 8192 байт. Компилятор сообщает о неиспользуемой исходной функции `quat_to_euler`; ошибок компиляции и линковки нет. Размеры могут измениться при другой конфигурации или версии инструментов.

В проверочной среде был установлен `IDF_COMPONENT_MANAGER=0`: определение процессов внутри контейнера вызывало ошибку вспомогательного менеджера. Внешних управляемых компонентов у проекта нет; все требуемые драйверы включены в исходники. Это настройка окружения сборки, а не изменение прошивки. Обычная инструкция запуска — в [README](../README.md).

## Панель

- `node --check web/app.js` — синтаксис корректен.
- `node tests/telemetry.cjs` — проверки проходят: raw/q/RPY, наклон и курс, интегрирование гироскопа, единицы измерений, разрывы времени, дробление Serial-потока, передача данных в модель, матрицу и графики, пауза и CSV.
- Дополнительно разобраны **120 реальных JSON-строк** из предоставленной диагностики: **120 приняты, 0 отклонены**. Файл диагностики не включён в публичный комплект. Свой файл можно проверить командой `node tests/telemetry.cjs path/to/diagnostic.txt`.
- Локальный Python-сервер отдаёт HTML, CSS и JavaScript с HTTP 200 и соответствующими типами содержимого; файлы за пределами `web` не публикуются.
- Проверены ссылки HTML на локальные CSS/JS и уникальность идентификаторов элементов.

Проверки JavaScript используют имитацию браузера и Serial-транспорта. Они подтверждают обработку пакетов, но не заменяют подключение настоящего COM-порта в Chrome/Edge. Отдельный запуск Windows `.bat` на Windows в этой среде не выполнялся.

## Что требует проверки на сборке друга

Выводы I2C и канал USB-консоли должны соответствовать плате; оси датчиков и калибровка MAG — монтажу. Комплект сохраняет ограничения исходного MEKF, перечисленные в [разборе фильтра](QAV250_EKF_review.md). Успешная компиляция не подтверждает точность ориентации на реальном коптере.
